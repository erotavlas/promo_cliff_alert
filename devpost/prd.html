Behavior and checks

Add subscription
  • Fields: name, category (custom reveals a text field), plan (own words, typed or dictated, LLM structures it), contact (required), start date, contract or not, full price, discount, promo end date.
  • Current price = full − discount; new price = full.
  • ☐ Contact empty: cannot save. ☐ Not a contract hides length. ☐ Save returns to the list.
Subscription list and "needs attention"
  • Row: icon (letter circle if no logo), name, status color, monthly now, monthly after promo, up/down arrow.
  • ☐ 30 days or fewer, or already past: in the top area. ☐ 31+ days: not. ☐ Color moves green to red.
  • Empty attention area: everything just shows in the list, all green.
Detail, cancel, and the Cancelled tab
  • Icon and name on top, then tenure, dates, promo, plan features, tappable contact, current (green) vs. new (red ▲) monthly and yearly.
  • Actions: Edit, Cancel, Negotiate. No delete on active.
  • ☐ Cancel moves it to Cancelled. ☐ Restore returns it. ☐ Delete only there.
Negotiate
  • Seeded results for an equivalent plan: provider, username, started at, ended at. Worse-than-start results hidden; sorted best first; the user picks any one.
  • No exact plan: closest match, else "no results yet". The script is still available, aimed at the current promo price.
  • ☐ Sorted, filtered, selectable. ☐ No-results path still produces a script.
Script
  • Tappable contact, brand icon and details at the top; short sections (opening, if they refuse) below.
  • Regenerate or tweak by typed or dictated instruction ("more aggressive").
  • LLM failure: a plain template script with a note. Never an empty screen.
  • ☐ Contact opens dialer or email. ☐ Sectioned. ☐ Refusal section cites seeded results. ☐ Failure shows the template.

Look and feel

Dark charcoal gray (not black, never pure white), lighter gray cards, soft off-white text, a modern sans-serif such as Inter with big bold prices, and green-to-red as the only strong color. Spacious and uncluttered. Mobile-first.
